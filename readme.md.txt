 Qovluq Strukturu

Code— Aptek növbəsi və Avtobus prioritet növbəsi üçün yazılmış proqram kodları.
Flowgorithm — Məsələlərin alqoritmik blok-sxemləri.
Images — Proqramın işləmə nəticələrinin ekran görüntüləri (screenshots).
Hesabat— Tam laboratoriya hesabatı sənədi.

 Məsələlər və İcra Olunma

1. Məsələ 1: Aptekdə növbə (FIFO)
    Müştərilərin növbəyə əlavə olunması, xidmət göstərilib çıxarılması və siyahının ekrana çap edilməsi.

2. Məsələ 2: Avtobus dayanacağında növbə və prioritet
   Yaşlı sərnişinlər (65 yaşdan yuxarı) üçün prioritetli növbə sisteminin modelləşdirilməsi.
